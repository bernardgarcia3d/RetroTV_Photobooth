# Receipt layout guides

These JPEGs are operator design guides. Use the paper outline as the final print boundary, keep important artwork inside the amber safe areas, and place photos only inside the blue photo boxes. Every current guide includes **two Operator Top Areas** before the photo windows, plus one or two footer areas below. Remove the guide labels and colored boxes from the final artwork before uploading it to the tablet.

| Guide | Photo window ratio | Photo arrangement |
| --- | --- | --- |
| `operator-template-guides-v3/photo-dominant-1-photo-portrait-guide.jpg` | 4:5 portrait | One photo |
| `operator-template-guides-v3/photo-dominant-3-photo-landscape-guide.jpg` | 16:9 landscape | Three photos stacked vertically |
| `operator-template-guides-v3/photo-dominant-4-photo-grid-guide.jpg` | 4:5 portrait | Two by two grid |
| `operator-template-guides-v3/photo-dominant-6-photo-grid-guide.jpg` | 4:5 portrait | Two by three grid |

The 1-photo, 4-photo, and 6-photo guides use portrait 4:5 windows. The three-photo guide uses 16:9 landscape windows. The app's camera preview, review, final preview, exported PNG/GIF, and printer raster use the same photo-window geometry and receipt height as these guides.
